# Rural Empowerment Center (REC) Website

Professional, modern, mobile-responsive website for Rural Empowerment Center — a Cameroon-based youth-led non-profit.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `our-work.html` — Our Work
- `field-action.html` — Field Action
- `impact.html` — Impact
- `partnerships.html` — Partnerships
- `partner-with-us.html` — Partner With Us
- `contact.html` — Contact

## Features

- Fully responsive (desktop, tablet, mobile)
- Accessible (skip link, focus states, alt text, labelled forms)
- SEO ready (titles, meta descriptions, Open Graph, sitemap, robots.txt)
- Clean, professional NGO design with forest-green / earth-tone palette
- Mobile hamburger navigation
- Contact form (client-side demonstration; connect to your backend or form service for production)

## How to use

1. Open `index.html` in a browser, or serve the folder with any static web server.
2. Replace Unsplash placeholder images with REC’s own photographs when available (update `src` and `alt` attributes).
3. Update the canonical domain in meta tags and sitemap if you use a different domain.
4. Connect the contact form to a real endpoint (Formspree, Netlify Forms, your own API, etc.).
5. Add a real favicon and any additional social media URLs once confirmed.
